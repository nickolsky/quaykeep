Всё для парка серверов — в одном окне

Для тех, у кого десятки VPS: VPN-узлы, сайты, домашние серверы. Без аккаунта, без облака, без телеметрии.

🔐

Зашифрованное хранилище

Серверы, пароли и закрытые ключи в одном файле: AES-256-GCM, ключ из мастер-пароля через Argon2id. Автоблокировка при простое и при блокировке компьютера.

⚡

Подключение в один клик

Двойной щелчок по серверу — вкладка встроенного терминала, или Windows Terminal, Terminal.app, ваш терминал в Linux. Пароль передаётся через SSH_ASKPASS, а не в командной строке.

🗝️

Встроенный SSH-агент

Ваши ключи для ssh, git и VS Code Remote-SSH: стандартный канал OpenSSH в Windows или SSH_AUTH_SOCK в macOS и Linux. Один щелчок — и сервер переходит с пароля на ключ.

⌨️

Умный терминал и редактор

Вкладки xterm.js с подсказками из истории сервера, команд и файлов; edit ФАЙЛ открывает редактор CodeMirror, который при необходимости сохраняет через sudo.

📁

Файловый менеджер SFTP

Две панели в стиле Far: этот компьютер и сервер. Копирование, перенос, переименование, права, перетаскивание, очередь передач.

📈

Мониторинг и аптайм

Проверка SSH и портов, CPU / память / диск, графики доступности за сутки… год, уведомления, когда сервер или порт падает.

🛡️

Файрвол и пробросы

Блокировка или белый список адресов для портов и всего сервера, включая Docker, с автоматическим откатом, если SSH пропадёт. Пробросы портов iptables и карта сети со всеми маршрутами.

📦

Скрипты установки

VLESS REALITY, Hysteria 2, AmneziaWG, Nextcloud, Seafile, File Browser, SFTP / FTPS, статические сайты, Docker. Результаты (ссылки, пароли) сохраняются с сервером, с QR-кодами.

🌍

Инвентаризация и сеть

ОС, контейнеры, службы, cron и таймеры, слушающие порты; регион, хостер и whois; трассировка с разбором по узлам.

ИИ-агенты — на коротком поводке

Quaykeep работает как MCP-сервер для Claude Code, Codex и других агентов. Агент просит — Quaykeep выполняет команду с данными из хранилища. Пароли и ключи агент не видит.

  • Доступ по умолчанию выключен и задаётся для каждого сервера: только чтение → перезагрузка → команды меню → полный.
  • Перезагрузка и удаление ждут вашего «Разрешить / Запретить»; системные папки удалить нельзя никогда.
  • Пароли и ссылки для входа из скриптов можно полностью скрыть от агентов.
  • Каждый вызов записывается в журнал, отказанные тоже; журнал виден вживую, как терминал.

Подключить Claude Code или Codex →

claude mcp add --scope user quaykeep -- \
  "/Applications/Quaykeep.app/Contents/MacOS/qk" mcp

# потом в Claude Code:
> что с vpn-frankfurt? перезапусти xray, если завис

Приватность по устройству

Всё хранится в папке данных на вашем компьютере. Необязательные онлайн-запросы (GeoIP, whois) можно выключить; обновления приходят из релизов этого проекта на GitHub.

  • Секреты никогда не попадают в командную строку, в файл на сервере или в журнал.
  • Изменения sshd и файрвола сначала проверяются и откатываются сами, если новый вход не удался.
  • Бэкапы всей папки данных в папку или на сервер по SFTP, по расписанию.
