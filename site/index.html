Everything a server fleet needs, in one window

Built for people who run dozens of VPS: VPN nodes, sites, home servers. No account, no cloud, no telemetry.

🔐

Encrypted vault

Servers, passwords and private keys in one file: AES-256-GCM with an Argon2id key from your master password. Auto-lock on idle and when the computer locks.

⚡

One-click sessions

Double-click a server: a tab in the built-in terminal, or Windows Terminal, Terminal.app or your Linux terminal. Passwords go through SSH_ASKPASS, never the command line.

🗝️

Built-in SSH agent

Your keys for ssh, git and VS Code Remote-SSH: the Windows OpenSSH pipe or SSH_AUTH_SOCK on macOS and Linux. One click switches a server from password to key login.

⌨️

Smart terminal & editor

xterm.js tabs with suggestions from the server's history, commands and files; edit FILE opens a CodeMirror editor that saves through sudo when needed.

📁

SFTP file manager

Two panels in the Far style: this computer and the server. Copy, move, rename, permissions, drag and drop, a transfer queue.

📈

Monitoring & uptime

SSH and port checks, CPU / memory / disk, uptime charts for a day to a year, notifications when a server or port goes down.

🛡️

Firewall & forwards

Block or allow-list addresses per port or server, Docker included, applied with an automatic rollback if SSH would break. iptables port forwards and a network map of every route.

📦

Install scripts

VLESS REALITY, Hysteria 2, AmneziaWG, Nextcloud, Seafile, File Browser, SFTP / FTPS, static sites, Docker. Results (links, passwords) saved with the server, with QR codes.

🌍

Inventory & network facts

OS, containers, services, cron jobs and timers, listening ports; region, hoster and whois; traceroute explained hop by hop.

AI agents, on a short leash

Quaykeep is an MCP server for Claude Code, Codex and other agents. The agent asks; Quaykeep runs the command with the credentials from the vault. The agent never sees a password or key.

  • Access is off by default and set per server: read only → reboot → menu commands → full access.
  • Reboots and deletions wait for your Allow / Deny; system folders can never be deleted.
  • Passwords and login links from scripts can be hidden from agents completely.
  • Every call is logged, denied ones too, and viewable live like a terminal.

Connect Claude Code or Codex →

claude mcp add --scope user quaykeep -- \
  "/Applications/Quaykeep.app/Contents/MacOS/qk" mcp

# then, in Claude Code:
> what's wrong with vpn-frankfurt? restart xray if it's stuck

Private by design

Everything lives in a data folder on your computer. Optional online lookups (GeoIP, whois) can be switched off; updates come from this project's GitHub releases.

  • Secrets never touch a command line, a file on the server or a log.
  • Changes to sshd and the firewall are validated first and rolled back automatically if a fresh login fails.
  • Backups of the whole data folder to a folder or a server over SFTP, on a schedule.
